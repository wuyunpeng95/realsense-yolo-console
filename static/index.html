QUICK START

开始使用 DepthSight

01

连接与采集

使用 USB 3 接口连接 D435i，并关闭 RealSense Viewer 等占用相机的软件。服务启动后自动采集；使用右上角按钮停止或重新开始。

02

人员识别与测距

绿色框表示检测到 person，标签包含置信度和轴向距离。短时编号不用于身份识别。躯干深度不足或波动较大时，结果表会标记测距质量。

03

深度与同步快照

深度固定按最近到最远距离映射为近黑远白。点击深度图查看最新帧对应像素的距离。快照 ZIP 包含 RGB、标注图、灰度深度、原始 16 位深度和元数据。

04

调节性能与效果

降低推理尺寸可减少 CPU 耗时，较大尺寸有利于识别较小目标。降低置信度可增加召回，也可能增加误检。关闭人员检测仍可查看双画面。

关于“真人检测”

当前实现是人员目标检测与深度辅助测距，不具备严格的防照片、防屏幕翻拍或活体认证能力。照片、屏幕、假人仍可能被识别为 person；有效深度不能证明真人。

遇到问题

相机断开后每约 2 秒重试连接。模型异常时仍保留画面采集，可在检测配置中重新加载模型。若 RGB 无法显示，请检查 USB 接口、相机是否被占用及服务日志。首次模型加载需要数秒。
